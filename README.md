# Silicon Purgatory

> **Esoteric Retro-Futuristic Tactical Combat Engine**  
> *Crafted by Arabella Blackthorne / Arabellanine*

Live Demo: [https://arabellanine.github.io/silicon-purgatory/](https://arabellanine.github.io/silicon-purgatory/)

## Overview
A zero-asset, browser-native tactical combat prototype implementing our sovereign **Tactical Cycle System**:
- **Full & Surge Phase Icons:** Weaknesses and critical strikes convert full cycle icons into half icons.
- **Punishing Defenses:** Misses and nulls deduct 2 icons; drains wipe remaining cycles entirely.
- **Tactical Command Menu:** Kinetic Cleave, Thermal Surge, Cryo Quench, Volt Pulse, Void Null, and Telemetry Patch.
- **Procedural Dungeon Floor:** Seeded BSP room generation with fluid grid locomotion and hostile process encounters.
