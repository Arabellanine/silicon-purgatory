# Silicon Purgatory

> **Esoteric SMT-Style Press Turn Tactical Combat Engine**  
> *Crafted by Arabella Blackthorne / Arabellanine*

Live Demo: [https://arabellanine.github.io/silicon-purgatory/](https://arabellanine.github.io/silicon-purgatory/)

## Overview
A zero-asset, browser-native tactical combat prototype implementing canonical **Shin Megami Tensei Press Turn mechanics**:
- **Full & Half Turn Icons:** Weaknesses and critical strikes convert full icons into half icons.
- **Punishing Defenses:** Misses and nulls deduct 2 icons; absorbs and repels wipe remaining turns entirely.
- **Tactical Command Menu:** Attack, Skill, Demon/Talk (negotiation stub), Pass.
